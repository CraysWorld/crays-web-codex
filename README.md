# CRAYS Net

CRAYS Net is the Primal-derived Nostr web application in the CRAYS ecosystem. It is part of the work on social communication alongside Personal and the native applications.

This repository contains the web application source. Read its package files for the application toolchain and its original license for the upstream terms.
